# Source code

This is the application package. See the [project README](../README.md) for downloads and features, the [developer guide](../CONTRIBUTING.md) for tests/builds, and the [documentation index](../docs/README.md) for current and historical guides.

| Folder | Contents |
| --- | --- |
| [core/](core/) | Logging, records, reference databases and spreadsheet export |
| [ocr/](ocr/) | Remnant OCR, item readers, rune scanning and text parsing |
| [ui/](ui/) | Desktop interface, review overlay and capture-region editor |
| [platform/](platform/) | Hotkeys, clipboard capture and game-window checks |
| [third_party/](third_party/) | Bundled library code, OCR model, item data and licenses |
| [fonts/](fonts/) | Interface fonts and license |
| [region_examples/](region_examples/) | Capture-region reference images |
| [atlas/](atlas/) | Versioned Atlas data, effects, artwork and provenance |
| [rune_icons/](rune_icons/) | Rune artwork used by manual review selectors |

See [the library list](../DEPENDENCIES.md) for Python dependencies and [the source index](../SOURCES.md) for individual modules.

# PoE2 Data Logger 1.3.2

Stable release from `main`, including the reviewed fixes since 1.3.1.3 Beta.

- Propagation review offers rune artwork and recipe-specific dropdowns in socket order. Save each chain part, correct saved runes on Expedition, and use Complete chain to finish the chain and advance its Expedition ID.
- Currency review groups recognized items, possible matches and unknown rows. Accepted corrections train local examples; final approval includes only approved rows and preserves the captured Start/End phase and Map ID.
- Corrected visible seeds are revalidated before linking them to opened remnants. Held waystone and unreadable tablet readings expose their correction controls; new tablet slots become visible immediately.
- Ritual OCR source text stays in developer tools. Scan reviews and manual controls remain scoped to their activity.
- Atlas gear rarity stepping respects its minimum value. Desktop layout improvements keep the shared controls accessible on smaller windows.
- CSV and Excel exports retain prior files and include map-linked item totals, frozen Atlas/gear setups and scan history. Repeated inventory scans replace the corresponding totals.
- Remove unused helpers and retired build triggers, update user guidance, and retain function-purpose notes throughout the first-party code.

The installer updates the runtime while retaining the user's Databases folder. Close any running logger before updating. Library sources, reference catalogs and license notices remain available.

# PoE2 Data Logger 1.3.2.4 Beta

- Add an **OCR Sensitivity** tab with separate **OCR Strictness** sliders for seed bars, remnant recipes, propagation, waystones, tablets, currency inventories and Ritual rewards. **0** accepts more tentative matches; **50** keeps the previous behavior; **100** requires manual confirmation before OCR results save. Each capture keeps its selected settings while recognition runs. Quantity, level, family, marked-position and capture-context checks remain enforced.
- Save each propagation chain part directly with **Approve** beside its recipe. **Complete chain** finishes the chain and advances to the next Expedition ID. Hide the extra Commit, Edit and manual-rune controls during ordinary propagation review; explicit manual entry remains available when requested, and saved rune corrections remain on Expedition.
- Make the live **Map #** and **Remnant #** indicators larger and easier to read.

This beta updates the runtime while retaining the user's **Databases** folder. Close any running logger before updating. The **1.3.2 stable release** remains available.
